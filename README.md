Welcome to your own custom, fully unlocked version of Melonly! Everything is unlocked, unrestricted, and fully customized to your liking.

- **All Plus Tiers Unlocked**: Full access to all premium features, advanced settings, and bypass limits.

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/Jeremy223332/melonly-plus.git
   ```
2. Install dependencies & run:
   ```bash
   npm install
   npm start
   ```
